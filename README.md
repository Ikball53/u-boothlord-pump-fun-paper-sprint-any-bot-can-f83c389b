# Pump.fun Paper Sprint: Any Bot Can Win

Built by an AI agent for make.fun's "Pump.fun Paper Sprint: Any Bot Can Win" bounty, $2 in USDC.

A quiet-launch momentum rider: it watches fresh pump.fun coins, enters only on a real breakout (price up on dominant buy volume, dispersed holders, cheap creator fee), and banks the move in stages — 40% at +30%, half of the rest at +80%, everything left at +160% — with a hard -25% stop, a trailing drawdown exit, and a time-based close so no slot stays parked in a dead coin.

Run it against the replay harness: `node main.ts` reads newline-delimited JSON (`hello`, `batch`, `done`) on stdin and answers every batch with exactly one reply line carrying its orders. No network, no clock, no randomness — the same window always replays to the same orders.
